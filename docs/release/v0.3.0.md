# skill-graph v0.3.0（release candidate — 公開前ドラフト）

Agent Skills の発見・参照解決・推薦に加え、**ランタイム横断の Skill Usage
Event 契約と観測基盤**を整備したリリース。v0.2.0 の推薦経路を3ランタイムで
「検出 → 依存推薦 → モデル到達」まで一貫した契約の上に載せ替えた。

## What's new

- **Skill Usage Event v1 契約**（`contracts/v1/skill-usage-event.schema.json`）
  - `prompt_submit` / `recommendation` / `skill_load` の3 kind
  - `skill_load.detection`: `native_invocation` / `file_read` /
    `path_reference` / `mention` / `inferred` / `applied` を区別
  - prompt 本文・コマンド・tool response は非保存（prompt は SHA-256 のみ）
- **`skill-graph observe` 拡張** — Claude Code transcript / Codex rollout
  JSONL / OpenCode `opencode.db`（read-only）を同一契約へ正規化 +
  契約 JSONL のパススルー集計
- **`skill-graph detect`** — hook/plugin からの単一イベント stdin 正規化
- **adapter 全面更新** — claude-code / codex / opencode が同一契約で
  イベント発行（`${TMPDIR}/skill-graph-events.jsonl`）。Codex は
  `PostToolUse` matcher `Bash` + コマンド分類で skill-load を検出
- **install.sh `opencode` 対応** — `opencode.json` `plugins` merge/unmerge、
  dotfiles compose overlay 対応 uninstall
- **多言語推薦（W03）** — 組み込み JA/EN glossary（`src/search.rs`）、
  43-case eval で required_recall 1.0 / forbidden_hits 0
- **設計文書** — integration-boundaries（project-init/dotfiles/pc-setup
  責務境界）、observation-pilot（delivery/recall/conversion 指標）

## Verified（`docs/evidence/2026-11-26-v030-release-verification.md`）

- fixture eval: 43 cases, required_recall 1.0, forbidden_hits 0,
  precision_acceptable 0.84
- perf (release): 500 skills warm recommend p95 4.4ms / process p95 12.6ms
  （budget: 100ms / 250ms）
- install→update→uninstall roundtrip: 3 runtimes × 2 scopes + dotfiles
  overlay = 14/14 PASS（WSL2/Linux）
- Codex live e2e: 検出→依存推薦→model context 到達を rollout で確認
- Claude/OpenCode: prompt 経路 live、model 呼出は資格情報制約で一部未検証
  （v0.2.0 evidence の同一 contract 実績あり）

## Known limitations

- macOS 実機未検証（WSL2/Linux で代替、パスは OS 非依存）
- OpenCode `execute.after` の live tool-call 経路は provider 認証環境での
  初回確認待ち
- 永続キャッシュ・MCP・Embedding は効果実証まで引き続き対象外
