# skill-graph v0.4.0

hook 実行と adapter ライフサイクルを Rust バイナリへ完全に内包し、
配布を**パッケージマネージャ標準経路**へ移行したリリース。
curl インストーラと shell adapter は廃止。CLI・Adapter・Contracts は
単一バージョン管理単位。

## What's new

- **`skill-graph hook <runtime> <mode>`** — v0.3.x の shell
  recommend-hook を Rust へ移植。Skill Usage Event 契約・
  `additionalContext` 注入形式は同一。常に fail-open（exit 0）。
- **`skill-graph adapter enable|disable|status <runtime>`** —
  `adapters/install.sh` の Rust 移植。claude-code `settings.json` /
  codex `hooks.json` への冪等 merge、opencode plugin の materialize
  （`~/.local/share/skill-graph/opencode-plugin/`）まで一貫。
  `--user`/`--project` スコープ、`--bin` でパス明示、`status` で
  enabled/disabled/legacy/broken を報告。
- **legacy 自動移行** — marker 識別により v0.3.x 形式
  （`skill-graph-recommend-hook`、`/skill-graph` plugin）を検出し、
  `enable` が新形式へ自動置換、`disable` が旧世代も含めて完全復元
  （dotfiles compose overlay 掃除を含む）。
- **パッケージマネージャ配布** — mise（`github:` backend、従来通り）、
  npm `@rebuildup/skill-graph`（platform optional deps 同梱、
  postinstall download/build なし。npm/Bun/pnpm 対応）、
  Homebrew `rebuildup/tap`、crates.io `skill-graph`。
  release 成果物は per-target tarball + `sha256sums.txt` のみ。
- **install.sh / adapters ツリー廃止** — shell 実装を全廃し、
  hook/plugin/adapter の全責務をバイナリに集約。

## Upgrade notes

- パッケージマネージャで新版を導入後、各 runtime で一度だけ
  `skill-graph adapter enable <rt>` を実行すると旧 hook/plugin 参照が
  自動置換される。
- **Codex**: コマンド文字列が変わるため `/hooks` で **一度だけ再 trust**
  が必要（ユーザー操作。trust 境界の迂回はしない設計）。
- 旧レイアウト（`~/.local/share/skill-graph/<ver>/` + `current`
  symlink + `~/.local/bin/skill-graph`）は `adapter status` が
  broken を報告しないことを確認後に削除可能。
- package 削除後も残った hook/plugin は fail-open のため runtime の
  通常動作を妨げない。

## 既知の制約

- bun は os/cpu gating を適用しない（全 platform package を取得。
  shim が正しい arch を選択するため動作影響なし）。
- musl / Windows native は対象外（WSL2 を利用）。
