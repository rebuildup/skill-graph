## Install

```bash
mise install
cargo build --release   # -> target/release/skill-graph
```

CLI usage: `discover` / `search` / `recommend` / `resolve` / `bench` / `perf` with repeated `--root`.

Claude Code (session-scoped, opt-in):

```bash
claude -p "<task>" \
  --plugin-dir <repo>/adapters/claude-code/skill-graph \
  --setting-sources project --no-session-persistence \
  --output-format stream-json --include-hook-events --verbose \
  --permission-mode bypassPermissions
```

Env: `SKILL_GRAPH_BIN`, `SKILL_GRAPH_ROOTS`, `SKILL_GRAPH_HOOK_LOG`,
`SKILL_GRAPH_HOOK_STATE`, `SKILL_GRAPH_HOOK_NOSTATE=1`.

## Supported runtimes

- Claude Code 2.1.x — hooks verified live (`UserPromptSubmit`,
  `PostToolUse` matcher `Skill`).
- Codex / OpenCode — not supported in v0.1.0 (CLI is runtime-agnostic).

## Verified scope (honest boundaries)

- Engine: parse/resolve/recommend contracts, duplicate & same-name
  identification, stopword filtering — unit + contract + bench verified.
- Live (Kilo anonymous free route, fixed model, n=1/cell): dep-chain
  injection converted to a real load (`quality-gate` → `system-quality`);
  graph contribution isolated vs Baseline and graph-stripped E arm;
  multi-turn drift re-recommendation; model suppressed all unnecessary
  loads; hook latency 24–47 ms.
- NOT verified: statistical significance (n=1), same-turn drift without
  skill loads (no hook by design), live same-name collision behavior
  (engine-layer only), Codex/OpenCode, long sessions, Bash payload shapes.

## Known limitations

- Text-match + `requires-skills` 1-hop admission only; no stemming/
  semantics; English-only stopword list.
- No persistent cache, MCP, graph DB, or embeddings (deferred until
  benefit is proven).
- Verification used an anonymous free tier (~200 req/hour/IP); results
  are directional, not a statistical claim.

## Uninstall

- Delete `target/release/skill-graph`; no config/log/cache is created.
- Adapter is session-scoped (`--plugin-dir`); nothing persists. If ever
  installed via `claude plugin`, `claude plugin uninstall skill-graph`.
- Hook state/log lives only under `${TMPDIR}/skill-graph-hook-*`;
  `SKILL_GRAPH_HOOK_NOSTATE=1` disables writes.
