# skill-graph v0.5.0

v0.4.0 の全機能を維持したまま、完成品質監査（#144、R1–R25 で収束）
による堅牢化修正を適用し、**npm・crates.io・Homebrew・mise の全配布
チャネルへの正式公開を完了した先行完成版**。prerelease ではない。

## What's new

v0.4.0 からの機能追加はない。差分は監査で摘出・修正された欠陥の
修正のみで、公開インターフェース・イベント契約・保存形式に互換性の
変更はない。

- **セキュリティ・堅牢性**: skill frontmatter の YAML alias/ネスト深度
  によるリソース枯渇の遮断、adapter の payload 削除・symlink 取り扱い
  の厳格化、MCP の pipelined request に対する admission bound、
  discovery/observe の保持量・CPU 増幅の上限化 など（詳細は #144 の
  ラウンド記録と `docs/specs/contracts.md` の不変条件節）。
- **配布の完遂**: v0.4.0 で未完了だった npm `@rebuildup/skill-graph`
  （+4 platform packages）と crates.io `skill-graph` への publish を
  実施。Homebrew tap formula・mise `github:` backend と合わせて
  全チャネルが v0.5.0 を提供する。

## Upgrade / 移行

- v0.4.0 からは各パッケージマネージャの通常 upgrade 手順で移行する
  （`mise use -g github:rebuildup/skill-graph@0.5.0`、
  `npm install -g @rebuildup/skill-graph@0.5.0`、
  `cargo install skill-graph --version 0.5.0`、
  `brew upgrade rebuildup/tap/skill-graph`）。
- hook/adapter の設定形式・イベント契約は v0.4.0 と同一のため、
  `adapter enable` の再実行は不要（`adapter status` で確認可能）。
