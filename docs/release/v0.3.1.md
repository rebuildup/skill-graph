# skill-graph v0.3.1

v0.3.0 の観測・推薦基盤はそのままに、**一般利用者向けの導入・更新・削除経路**を
整備したパッチリリース。CLI と adapter を同一リリース成果物として
バージョン管理し、更新時の hook 重複・旧参照残存を構造的に排除する。

## What's new

- **root `install.sh`** — GitHub Release から OS/arch 別 tarball +
  adapters bundle + `sha256sums.txt` を取得・検証し、
  `~/.local/share/skill-graph/<version>/` + `current` symlink +
  `~/.local/bin/skill-graph` へ配置。`--runtime` で adapter を opt-in
  有効化、`--uninstall`/`--purge` で復元。PATH・shell rc は変更しない。
  release asset として同梱されるため
  `curl -fsSL .../releases/latest/download/install.sh | bash` で導入可能。
- **adapter エントリの marker 識別** — hook/plugin エントリを埋め込み
  パスではなく `skill-graph-recommend-hook` / `/skill-graph` marker で
  識別。version ディレクトリ差し替え後の再 install・uninstall で旧参照が
  残らず、重複 hook が発生しない。uninstall は binary/adapter ファイルが
  既に無くても動作する。
- **runtime lifecycle 文書** — `adapters/README.md` に runtime 別の
  config owner / enable / disable / restore 表と、Codex `/hooks` trust が
  コマンド文字列の hash-pin であること・`current` symlink で version
  非依存パスを維持する設計根拠を明記。
- **`install.sh` release asset 同梱** — release workflow が
  `install.sh` を asset として出力。

## Upgrade notes

- v0.3.0 で導入済みの環境は、root `install.sh` の再実行（または同等の
  versioned layout への移行）で `current` symlink 経由の安定パスに
  移行できる。marker 識別により旧 version 参照は自動除去される。
- Codex の `/hooks` trust はコマンド文字列が変わらない限り更新をまたいで
  有効。`current` symlink 経由のパスを使えば再 trust は不要。
