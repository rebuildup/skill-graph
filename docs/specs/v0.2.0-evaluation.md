# v0.2.0 評価設計 — 190-session 統計との比較可能性（#57）

Date: 2026-11-25
Issue: #57
Status: design（パイロット実行は別 Issue）

## 目的と制約

v0.1.0 の 741 calls / 190 sessions 統計は元ログ未発見の reported context
value であり、**正解ラベルにも比較基準にも使えない**。v0.2.0 では
「同等規模の観測を新規に、交絡を制御して」集める。呼び出し回数の増加は
成功条件にしない。

## データ源（新規大量ログを前提にしない）

1. **既存 transcript（第一候補・read-only）**
   - Claude Code: `~/.claude/projects/**/*.jsonl` — `observe` コマンドで
     `tool_use`/`Skill` を集計済み（#55）。ただし初回観測で記録率が低い
     （31 files / 22 sessions → 1 load）ことが判明。skill 本文注入型の
     ロードは transcript に `Skill` tool_use として現れない可能性があり、
     **transcript は invocation の下限値**として扱う。
   - Codex: `~/.codex/sessions/**/rollout-*.jsonl` — 形式調査後に observe
     パーサを追加。
   - OpenCode: `opencode.db` — schema 調査後に同様。
2. **opt-in hook log（補助信号）**
   - `SKILL_GRAPH_HOOK_LOG` JSONL は推薦発行・dedup・skill-load・latency を
     記録。導入群のみが生成するため対照群には使えないが、推薦→ロードの
     conversion はここでしか観測できない。
3. **評価 dataset（推薦性能側）**
   - `evals/dataset/cases.jsonl` + #54 で追加する日本語・高 df ケース。
   - ラベルは人手定義であり transcript から逆算しない。

## 指標

| 指標 | 定義 | 優先度 |
|---|---|---|
| Invocation Recall | 必要 skill が実際にロードされた割合 | 最優先 |
| 不要ロード率 | 推薦・ロードされたが不要だった割合 | 高 |
| timeliness | 推薦が必要判断に間に合ったか | 中 |
| context 消費 | 追加コンテキスト量 | 中 |
| 成果物品質 | タスク成果への効果 | 低（定性） |
| 呼び出し回数 | 総ロード数 | 副次（単独で成功扱いしない） |

## 交絡対策 — 採用方針

導入前後の単純比較は、作業内容・利用可能 skill・モデルの差で無効化される。
採用する設計:

- **同一プロジェクト・同一期間内の A/B 交互**: skill-graph 有効/無効を
  セッション単位でランダム化（例: 日単位交互 or prompt hash による決定的
  割当）。モデル・corpus・タスク分布を期間内で揃える。
- **層別**: runtime（claude/codex/opencode）と corpus 規模で層別集計。
  runtime 間の直接比較はしない。
- **期間正規化**: 回数指標は session あたり・日あたりに正規化。
- **推薦精度と呼び出し性能の分離**: dataset eval（推薦性能）と観測
  （呼び出し性能）を別々に報告し、混ぜない。

## パイロット計画（骨子）

1. **準備**: 対象 runtime を1つに固定（Claude Code 推奨: transcript 基盤が
   最も整備済み）。`SKILL_GRAPH_HOOK_LOG` を opt-in で有効化した開発者の
   実 session を観測対象にする。
2. **期間**: 最低 2 週間 or 50 sessions/群 のいずれか早い方。目標は
   190 sessions 級の規模だが、まずパイロットで指標が算出可能かを確認する
   （release gate: "opt-in 観測で conversion 指標が算出可能"）。
3. **判定**: Invocation Recall と不要ロード率の群間差を効果量として報告。
   n が小さい場合は信頼区間を併記し、有意差を主張しない。
4. **旧統計との関係**: 741/190 は参考値として併記するのみ。数値の一致を
   目指さない。

## 未決事項

  決定する。
- Codex/OpenCode の観測 parser 完成度がパイロット対象 runtime を制約する。
