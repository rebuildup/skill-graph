Date: 2026-11-27
Status: draft（Issue が正本）
Base: v0.4.0 `release-0-4-0` + 完成品質監査（#144、R1–R25 収束）適用済みコード

## 位置づけ

v1.0.0 はパッケージの初回公開バージョンではない。**v0.5.0 が先行完成版**
として、現行完成候補（`v1.0.0.md` §1–§5 の全機能と監査収束後の品質）
を全配布チャネルへ正式公開し（prerelease ではない）、公開成果物の
実環境への導入・利用・更新・削除・統合を検証する。v1.0.0 は v0.5.0 の
実利用結果を踏まえた最終品質改善・検証を経て、完成を確定する版である。

v0.4.0 は GitHub Release・Homebrew tap まで公開されたが、npm /
crates.io への registry publish が未完了のまま残った。本版でその
公開を完遂する。

## 機能スコープ

コード上の機能差分は v0.4.0 tag からの完成品質監査修正（#144）のみ。
`v1.0.0.md` §1–§5（MCP server / `observe --summary` / 動的推薦 /
adapter / hook）の要求は変更しない。全機能・品質を現行完成候補の
まま維持する。

## 配布要件

- GitHub Release `v0.5.0` + per-target tarball + `sha256sums.txt`
  （release.yml、tag push で自動実行）
- npm `@rebuildup/skill-graph` + 4 platform packages
  （npm-publish.yml、`NPM_TOKEN` secret 必要）
- crates.io `skill-graph`（`cargo publish`、registry token 必要。
  公開前に `scripts/verify-crate-artifact.sh <manifest の crates
  digest>` で packaged bytes == 承認 manifest digest を要求し、
  公開後に `scripts/verify-crates-published.sh <digest>` で
  static.crates.io の .crate を照合する — crates.io version は
  immutable で同 version 再 publish は不可のため、不一致時の
  復旧は yank + 原因調査 + 新版とし、同 version 再公開を前提に
  しない）
- Homebrew `rebuildup/homebrew-tap` `Formula/skill-graph.rb`
  （version + sha256 を v0.5.0 release asset に更新）
- mise `github:rebuildup/skill-graph` backend（release asset を
  自動参照、追加作業なし）
- 全チャネルで stable として公開し、prerelease / beta 表記を使わない

## 実利用検証要件

公開済みパッケージを使い、以下を実環境で検証する。workflow の静的
確認やローカルビルドを公開成果物の実利用と混同しない。

- 各チャネルからの新規 install（npm/bun/pnpm・cargo・brew・mise）
- `skill-graph --version` = 0.5.0 での discover/recommend/hook/MCP

## tag / freeze / 承認の単一契約（#225 A15、#224 と統合）

- release tag `vX.Y.Z` は `release-X-Y-Z` branch の head commit を
  指す。tag commit = freeze 対象 commit = 公開 commit の三者は
  同一 SHA で束縛される。
- artifact-verify.yml の freeze run は `head_sha == tag commit`・
  `event == push`・`completed/success` のみが promotable。
  `freeze-manifest.json`（run_id・run_attempt・head_sha・全
  artifact digest）が承認記録であり、release/npm/crates の全
  promotion はこの manifest を消費する。tag を打ち直す・別 run を
  指す・attempt を跨ぐ差し替えは全て拒否される。
- `main` への統合は release 公開後の別 PR であり、tag/freeze/
  承認の対象 SHA とは独立（merge commit は公開物に含まれない）。
