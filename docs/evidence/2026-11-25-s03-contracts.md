Issue: #5
Branch: `5` → `release-0-1-0`

## Change

- Added `contracts/v1/` JSON Schemas for `SkillSummary`, `DiscoveryOutput`, `RecommendationList`, and `ResolveResult`.
- Added `docs/specs/contracts.md` recording the v1 contract, state distinctions, ambiguity rule, and no-output condition.
- Made resolve output typed as `model::ResolveResult` (`name` / `path` / `unresolved`) and `SkillSummary.availability` a typed enum (`available` / `parse_error`).
- Added `tests/contract.rs` covering schema JSON validity, discovery/recommendation/resolve output shape, empty recommendation output, and ambiguous-name resolution.

## Contract decisions

- `availability` is discovery-time only; loaded/applied/unobservable states require runtime observation and are not mixed into v1 summaries.
- Same-name skills are never silently uniquified: `ResolveResult::Name` carries `ambiguous` and all candidates.
- Empty recommendation is the no-output contract: `recommend` returns `[]` and the JSON output is `[]`.
